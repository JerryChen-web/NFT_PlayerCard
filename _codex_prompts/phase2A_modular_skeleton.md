# Phase 2A Modular Skeleton

## Goal

Create the modularization development branch and add a safe folder skeleton while preserving the online single-file version.

## Constraints

- Do not modify root `index.html`.
- Do not split CSS, JavaScript, or player data yet.
- Do not add major features.
- Do not change UI, animations, market behavior, Oracle behavior, Metadata behavior, or Studio behavior.
- Keep GitHub Pages deployable from the root `index.html`.

## Deliverables

- Branch: `phase2-modularization`
- Legacy backup: `legacy/v1.0-single-file-online/index.html`
- Skeleton folders: `src/css`, `src/js`, `src/js/ui`, `src/data`, `assets`, and `_codex_prompts`
- Agent guidance: `AGENTS.md`
